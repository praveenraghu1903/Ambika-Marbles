# Ambika Marbles and Tiles

Static website for Ambika Marbles and Tiles (Gairatganj and Silwani).

Plain HTML, CSS and JavaScript. No build step.

## Run locally

Open `index.html` in a browser, or run `python3 -m http.server` in this folder.

## Add your phone number

Edit `site.js` and set `PHONE` (digits with country code, for example `919876543210`).
The Call and WhatsApp buttons appear automatically.

## Publish on GitHub Pages

Repository Settings, Pages, deploy from branch `main` and folder `/ (root)`.
The site will be live at `https://praveenraghu1903.github.io/Ambika-Marbles/`.
